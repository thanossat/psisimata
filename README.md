# Ψησίματα Σχολής

Εφαρμογή καταγραφής του κόστους ψησίματος στη σχολή κεραμικής: **5 €/kg ανά ψήσιμο**. Το κόστος επιμερίζεται στους **Θάνο, Ηλιάνα και Δημήτρη**.

Η εφαρμογή λειτουργεί στο GitHub Pages: **https://thanossat.github.io/psisimata/**

## Λειτουργίες

- Καταχώριση αντικειμένου με φωτογραφία (από την κάμερα ή τη συλλογή), βάρος σε γραμμάρια, αριθμό ψησιμάτων, καλλιτέχνη και ημερομηνία.
- Υπολογισμός κόστους: `βάρος (kg) × ψησίματα × τιμή`. Τα «Κοινά» αντικείμενα μοιράζονται ισομερώς στους τρεις.
- Σύνοψη μήνα ανά καλλιτέχνη.
- Σύνοψη έτους με ανάλυση ανά μήνα και αρχείο όλων των ετών.
- Αντιγραφή της σύνοψης μήνα ή έτους για αποστολή.

## Πού αποθηκεύονται τα δεδομένα

Όλα τα δεδομένα βρίσκονται σε αυτό το repository και κάθε αλλαγή γίνεται commit:

```
data/
  index.json            ← τιμή €/kg και λίστα μηνών με καταχωρίσεις
  2026/
    2026-11.json        ← οι καταχωρίσεις του μήνα
photos/
  2026/
    11/
      20261104-thanos-xxxx.jpg
```

Κάθε καταχώριση κρατά την τιμή με την οποία καταχωρίστηκε. Αν αλλάξει η τιμή, τα παλιά ποσά δεν μεταβάλλονται. Οι φωτογραφίες συμπιέζονται στο κινητό (έως 1600 px, JPEG) πριν ανέβουν.

## Ρύθμιση (μία φορά ανά συσκευή)

Χωρίς token η εφαρμογή λειτουργεί μόνο για προβολή. Για καταχωρίσεις χρειάζεται ένα fine-grained token:

1. Ανοίξτε το https://github.com/settings/personal-access-tokens/new
2. Repository access: **Only select repositories**, και επιλέξτε **psisimata**
3. Repository permissions: **Contents: Read and write**
4. Generate token. Στην εφαρμογή ανοίξτε **Ρυθμίσεις**, επικολλήστε το token και πατήστε **Αποθήκευση & έλεγχος**

Το token αποθηκεύεται μόνο στον browser της συσκευής.
